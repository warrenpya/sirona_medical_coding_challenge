# Sirona Medical Coding Challenge

Completed by Paul Yarin 8/8/2026

## Installation
Esnure Python and pip are installed.

Clone the repository and navigate into the project directory.

Install the dependencies:

```bash
pip install -r requirements.txt
```

## Run the application

From the project root, run:

```bash
py main.py
```


## Run the tests

From the project root, run:

```bash
py -m pytest test.py
```
